# 04 实战策略与时间管理（冲国一打法）

> 90 分钟窗口（8:00–9:30），要把 **组装 + 编程联调 + 运行** 全压进去。
> 决定名次的不是"会不会"，而是**稳定、快、不出错**。下面是可执行的打法。

---

## 一、时间分配（建议）

| 阶段 | 目标时长 | 关键产出 |
|---|---|---|
| 硬件组装 | 6–8 分钟 | 装好通电、相机机械臂被识别 |
| 读任务书 + 确定方案 | 3 分钟 | 明确识别什么、分拣到哪、协议格式 |
| 取图 + 调光/焦 + ROI | 5 分钟 | 一张稳定清晰可用的图 |
| 识别跑通（单件） | 10 分钟 | 单件正确分类 + 像素坐标 |
| **手眼标定 + 验证** | 12 分钟 | 像素→物理坐标误差 <2mm |
| 通信打通 | 8 分钟 | 视觉→机械臂收到正确指令 |
| 单件全流程 | 8 分钟 | 抓→放对位置 |
| 8 件联调 + 容错 | 余下时间 | 顺序、节拍、防碰撞 |

> 原则：**先跑通端到端最小闭环（1 件能分拣对），再优化精度和速度**。不要在某一环卡死。

---

## 二、分工（2 人）

- **A（视觉手）**：组装相机模组 → 取图/调光/识别/标定/通信输出配置。
- **B（机械臂手）**：组装机械臂/接线 → 写/调 Python 抓放逻辑、坐标、吸盘参数。
- 标定环节两人配合：A 看软件读数，B 操作机械臂走点。
- 约定好**通信协议格式**（谁服务端、端口、字段顺序），写在纸上贴桌面。

## 四、易丢分点与对策

| 风险 | 后果 | 对策 |
|---|---|---|
| 标定误差大 | 抓偏、放错区 | 标定板水平、调焦调光、标完必验证 |
| 光照变化 | 识别不稳 | 固定光源亮度，加 ROI，参数留余量 |
| 抓取高度不对 | 吸不住/撞工件 | 实测 Z_PICK，吸盘加延时 |
| 多件碰撞 | 工件移位/连带 | JUMP 模式、放置区间距拉开、按距离排序抓取 |
| TCP 粘包/断连 | 漏指令、卡死 | 按 \n 分行解析、加回执、加重连 |
| 暴力操作损坏设备 | 被终止比赛 | 轻操作、超限位置不强行运动 |
| 紧张漏步骤 | 浪费时间 | 按本文清单逐项打勾 |

## 五、现场心态与流程纪律
- 拿到任务书先**通读评分标准**，按分值高的环节优先保。
- **保底优先**：先确保"能分拣对几件"拿到基础分，再追求 8 件全对 + 速度。
- 每完成一个里程碑（识别通/标定通/通信通/单件通）就**存一次**，别让进度丢失。
- 留 5–10 分钟做 8 件完整演练，别等到最后一刻才第一次跑全流程。
- 9:30 准时停手，按指定路线离场。
