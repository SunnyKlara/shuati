# 02 DobotVisionStudio 视觉流程（环节2 核心）

> DobotVisionStudio 是越疆的机器视觉软件，**图形化拖拽 + 1000+ 图像处理算子**，支持
> 颜色识别、条码/二维码识别、字符识别(OCR)、测量、标定、定位对位、图像处理等。
> 本文按比赛实际用得到的流程组织：**手眼标定 → 识别 → 输出坐标 → 通过 TCP 发给机械臂分拣**。

---

## 一、整体数据流

```
工业相机取图 → DobotVisionStudio 流程
   ├─ 预处理（灰度/二值化/滤波/ROI）
   ├─ 识别定位（特征匹配 / 颜色 / 形状 / 二维码 / 字符OCR）
   ├─ 标定转换（像素坐标 → 机械臂世界坐标 / 手眼矩阵）
   └─ 结果输出（TCP/串口）→ Dobot Magician → 抓取分拣
```

DobotVisionStudio 用「方案/流程」把算子串成一条处理链，每个算子有输入/输出，最后用
**通信输出模块（TCP Client/Server 或 串口）** 把识别结果（类别 + 坐标 + 角度）发出去。

---

## 二、手眼标定（最关键、最容易出错）

手眼标定的目的：把**相机像素坐标 (u,v)** 转换成**机械臂可执行的物理坐标 (X,Y)**。
本套件是**相机固定在支架上俯拍（Eye-to-Hand，眼在手外）**，标定后得到一个仿射/单应变换矩阵。

### 方法 A：DobotVisionStudio 内置 N 点标定（推荐）
1. 相机取图，识别标定板上的特征点（圆点/棋盘格角点）。
2. 用「标定」算子做 **9 点（或 N 点）标定**：机械臂末端依次走到这些已知物理点，
   记录每个点的「像素坐标 ↔ 机械臂坐标」对。
3. 软件解算出像素→物理坐标的变换矩阵，保存。

### 方法 B：三色点标定（老版 VisionDemo 流程，作为理解参考）
> 来自老版 Robot Vision Kit 文档，原理相通：
1. 标定板放相机下，选择 "Matrix Calculate"，GetImage 后软件自动记录红/绿/蓝三点在**相机下**的坐标。
2. 末端换上**笔架工具**，手动拖动机械臂（配合软件 Jog 微调），**严格按 红→绿→蓝 顺序**
   把笔尖移到三个点，分别点 Red/Green/Blue Point 按钮记录机械臂坐标。
3. 点 OK 完成标定。**顺序不能错！**

### 标定避坑
- 标定前**先调焦**（取下光源调焦，调完装回），保证图像清晰。
- 调光源亮度到标定点能被稳定检测；亮度过曝/过暗都会丢点。
- 标定板必须**水平**放在检测平面（与实际工件同一高度面），否则有视差误差。
- 标定完做**验证**：放一个已知位置的工件，看软件算出的坐标和实际是否吻合（误差应 < 1–2mm）。

## 三、识别方法选型（按任务书要求选）

| 任务类型 | 推荐算子 | 要点 |
|---|---|---|
| **形状分拣**（圆/方/三角等） | 二值化 + Blob/轮廓分析 + 几何特征（面积、圆度、边数） | 比赛"每种形状各1件" → 大概率是形状识别 |
| 颜色分拣 | HSV 颜色提取 | 调 H/S/V 范围 + minArea/maxArea 滤小噪点 |
| 特征匹配定位 | 模板匹配 / 特征匹配算子 | 先示教模板，输出匹配位置+角度 |
| 二维码识别 | 条码/二维码识别算子 | 直接输出字符串 |
| 字符识别 | OCR 算子（需训练字符库） | 字符要清晰、固定字体 |

> ⚠️ 比赛说"发放需检测物品（每种形状各1件）"，再加培训含"图像模型训练/识别"，
> 高概率任务是：**按形状（可能叠加颜色/字符）把8个随机摆放的工件分拣到对应区域**。

### HSV 颜色调试要点（如涉及颜色）
- H=色调，S=饱和度，V=亮度；分别设 low/high 范围框住目标颜色。
- minArea/maxArea 过滤过小/过大区域，去掉干扰。
- 取图后**记住目标在画面里的位置**，逐色调参，调到"目标全显示、其他色全消失"。

## 四、输出坐标给机械臂

1. 识别算子输出：**类别（形状/颜色/字符）+ 像素中心坐标 + 旋转角**。
2. 经标定矩阵转换为**机械臂物理坐标 (X, Y)**（Z 由工件高度固定）。
3. 用**通信输出模块**（TCP/串口）按约定格式发送，例如：
   ```
   类别,X,Y,R\n     例： circle,210.5,-30.2,15.0
   ```
4. 机械臂端（DobotVisionStudio 联动 或 Python 脚本）解析后执行抓取-移动-放置。

> 通信格式必须**视觉端和机械臂端约定一致**，详见 `03_Python与TCP通信.md`。

---

## 五、调试顺序建议（环节2 内）
1. 先**取一张稳定清晰的图**（焦距、光源、ROI）。
2. 跑通**识别**（单个工件能正确分类 + 给出像素坐标）。
3. 做**标定**并验证像素→物理坐标准确。
4. 打通**通信**（视觉→机械臂能收到一条正确指令）。
5. 跑**单件全流程**（识别→抓→放对位置）。
6. 最后上 **8 件随机摆放**联调，调节拍间隔、避免碰撞。
