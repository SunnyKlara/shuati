# 00 真实系统全景与备赛总纲

> 本文基于**官方案例程序源码 + 赛前必读.docx + 物料清单.docx**重新梳理，
> 替代此前基于 PDF 推断的"形状分拣"版本。所有结论可在代码中逐行验证。
>
> 一句话定位：**这不是"单臂识别形状分拣"，而是一条"双臂 + 传送带 + RFID + 深度学习 + 视觉 + 语音"的智能产线联调赛。**

## 一、真实任务到底是什么

### 物料：3 套主题，现场任务书指定其一，每套 8 件（M001–M008）

| 主题 | 4 个类别（每类 2 件） | 类别代码（代码里的 classes）|
|---|---|---|
| **快递物料** | 电子产品 / 食品 / 服装 / 书籍 | （需按主题改标签）|
| **工业自动化** | 机器人 / 机械臂 / PLC / 视觉系统 | `1.jqr` `2.jxb` `3.plc` `4.sjxt` |
| **自动驾驶** | 交通锥 / 智能路障 / 仿真测试 / 测试车辆 | （需按主题改标签）|

> 代码里默认 `classes = ('1.jqr','2.jxb','3.plc','4.sjxt')`，对应**工业自动化**主题。
> 另两套主题需要自己采图重训模型 + 改标签名。**备赛要把三套都准备好。**

### 每件物料的两层信息
1. **图案/外观** → 由 **ResNet18 深度学习模型**识别出"类别"。
2. **背面 RFID 卡** → 存 `省份;运输时间`（如 `广东省;1天`），由 RFID 读卡器读出。

物料清单的隐藏规律（出题点）：
- 4 个**类别**，每类恰好 2 件。
- 4 个**原产地省份**（广东/浙江/山东/四川），每省恰好 2 件。
- 4 种**运输时间**（1/2/3/4 天），每种恰好 2 件。

> 这意味着分拣维度可能不止"类别"——任务书可能要求**按省份**或**按运输时间**分拣。备赛要想到这层。

## 二、系统由 6 个程序组成（TCP 互联）

| 模块 | 源码位置 | TCP 角色 | 端口 | 关键职责 |
|---|---|---|---|---|
| **下料机械臂** | `下料机器臂/Main.py` | **服务端** | **8081** | 总调度中枢，开多线程接所有客户端；按类别码垛 |
| **上料机械臂** | `上料机器臂/Main.py` | 客户端 | →8081 | 码垛区取料→RFID位→传送带；控制传送带电机 |
| **深度学习分类** | `深度学习分类/main.py` | 客户端 | →8081 | ResNet18 推理 + 读 RFID 解码文本 |
| **RFID** | `RFID64bit/RFID.py` | 串口读卡 | COM | 读 M1 卡块1，输出 `省份;时间` 到 json |
| **视觉** | `视觉工程文件/40307.poj` | 客户端 | →8081 | DobotVisionStudio 拍照、读编号、存 img.bmp |
| **语音**（可选） | `语音/main.py` | 客户端 | →8081 | 百度云 ASR，语音控制机械臂 |

### TCP 连接顺序（写死在下料机 accept 顺序里，必须严格遵守）
```
1) 先启动  下料机器臂/Main.py     → 阻塞在 accept() 等连接
2) 再启动  视觉工程(.poj)          → 成为 tcpCliSock1（视觉端）
3) 再启动  深度学习分类/main.py    → 成为 tcpCliSock2（分类端）
4) 再启动  上料机器臂/Main.py      → 成为 tcpCliSock3（上料端）
5) （可选）语音/main.py            → tcpCliSock4（代码中默认注释掉）
```
> ⚠️ 顺序错 = 角色错位 = 系统逻辑全乱。这是头号卡场点，必须背到肌肉记忆。

## 三、一件物料的完整旅程（端到端时序）

```
┌ 启动：下料机终端输入任意键 或 语音"开始" → 给上料机发 "run"
│
├ 上料机：码垛区抓料(P1，按50mm间距码垛算法) → 放到RFID读卡位(P2) → 发 "arrive1"
│
├ 下料机收"arrive1" → 命令视觉 "getphoto1"（在RFID位拍照/读编号 M00X）
│
├ 视觉识别出 "M..."编号 → 发给下料机 → 下料机回 "OK"
│
├ 上料机收"OK" → 从RFID位抓料(P2) → 放到传送带(P3) → 启动传送带电机
│      └ 光电传感器检测到料到位 → 停传送带 → 发 "arrive2"
│
├ 下料机收"arrive2" → 等5秒(图像稳定) → 命令视觉 "getphoto2"（拍物料本体存img.bmp）
│
├ 分类系统：predict(img.bmp) → ResNet18 输出类别 + 同时 get_decoded_text() 读RFID "省份;时间"
│      └ 把类别发给下料机
│
├ 下料机：sampleClss.index(类别) → 抓取(P6) → 放到该类别垛位 P3[index][垛][层]
│      └ add_up[index]++，每类2垛×2层叠放
│
└ sum(add_up) < 8 → 发"run"继续下一件；==8 → 全部完成，停止
```

## 四、各模块关键技术参数（备赛要背）

### 4.1 深度学习分类（识别核心）
| 项 | 值 |
|---|---|
| 网络 | ResNet18（`pretrained=False`，加载本地 `model/resnet18.pth`）|
| 分类数 | 4（改 `fc` 层）|
| 输入 | 224×224，灰度转3通道 |
| 归一化 | mean=[0.5,0.5,0.5] std=[0.5,0.5,0.5] |
| 损失/优化器 | CrossEntropyLoss / SGD(lr=0.001, momentum=0.9) |
| 学习率 | StepLR(step_size=7, gamma=0.1) |
| 推理图源 | `深度学习分类/img.bmp`（视觉拍照存的）|
| 输出 | `(类别名, 编号, 置信度)` |
| 模型文件 | `model/model.pkl` |

赛前必读官方提示：
- 自定义数据集**每类 ≥2 张**（建议裁剪压缩，太大训练慢）。
- 迭代 **50 次左右**（不能太大，会过拟合）。
- 模型不理想时跑 `train.py` 重训；条件不够就用默认模型 + 优化预处理/光照。

### 4.2 RFID
- 卡片：MIFARE Classic（M1 卡），DLL `comPro64.dll`（64位）。
- 读**块1（扇区0）**，默认密钥 `FFFFFFFFFFFF`。
- 取**前10字节**，按 `gbk→gb2312→utf-8→ascii` 解码。
- 数据格式 `省份;时间`，结果存 `card_result.json`。
- 自动扫 COM2–COM20，波特率 115200。
- 坑：端口占用 → 拔插 USB；**RFID.py 保持运行不要中断**。

### 4.3 机械臂（与旧材料的重大差异）
| 项 | 真实值 | 旧材料（错） |
|---|---|---|
| 末端 | **夹爪** `SetEndEffectorGripper` | 吸盘 |
| 末端参数 | `SetEndEffectorParams(api, 59.7, 0,0, 1)` 夹爪长59.7mm | — |
| 运动指令 | `SetPTPCmdEx`（带Ex自动等待）| SetPTPCmd |
| 运动模式 | mode=1（MOVJ）| — |
| 跳跃参数 | `SetPTPJumpParams(api, 100, 110)` | — |
| 传送带 | `SetEMotor(api, 0, enable, speed, 1)` | 无 |
| 光电传感器 | `SetInfraredSensor` / `GetInfraredSensor` 接GP2口 | 无 |
| 清警报 | `ClearAllAlarmsState(api)` 启动必做 | — |
| 示教读坐标 | `GetPose(api)`（见读取座标.py）| — |
| 上料臂 COM | `COM16`（现场要改）| — |
| 下料臂 COM | `COM6`（现场要改）| — |

### 4.4 视觉软件
- 名称：**多功能机器视觉软件 3.1.6**（即 DobotVisionStudio，基于海康 MVS SDK）。
- 相机：海康工业相机 / K230 相机。
- 工程文件：`40307.poj`。
- 坑：USB 必须插 **USB3.0**（蓝口）否则卡顿/无图；参数错会崩溃 → **分步另存不同文件名**。

### 4.5 语音（可选加分）
- 百度云 AipSpeech ASR，代码自带 APP_ID/API_KEY（需联网）。
- 识别"原点/开始/前后左右上下+数字厘米"控制机械臂。
- 下料机里默认**注释掉**，主流程不依赖。

## 五、备赛准备清单（比赛前必须完成的事）

> 这是"备赛"的核心——把现场要用的东西，提前在自己设备/电脑上准备好、练熟。

### A. 环境与资料准备（详见 `01_备赛环境搭建清单.md`）
- [ ] 比赛电脑环境包里的软件全部会装：Python3.10、DobotStudio、视觉软件3.1.6、海康MVS SDK、VSCode
- [ ] Python 依赖会装：torch/torchvision、opencv-python、Pillow、pyaudio、baidu-aip、numpy
- [ ] 6 个案例程序能在本机跑起来（哪怕无硬件先跑通能跑的部分）
- [ ] 三套主题物料图片备齐（已在 `物料/` 下）

### B. 必须练到肌肉记忆的操作
- [ ] **硬件组装**：双臂 + 相机 + 传送带 + 光电 + RFID，10 分钟内装好
- [ ] **改 COM 口**：设备管理器查端口 → 改两个 Main.py
- [ ] **坐标示教**：用 `读取座标.py` 记录上料臂 P1/P2/P3、下料臂 P6 + 4类×2垛
- [ ] **模型推理/训练**：跑通 predict，会用 createTrainPhoto + train 重训三套主题
- [ ] **RFID 读卡**：单独跑通，确认输出 `省份;时间`
- [ ] **视觉工程**：会打开 40307.poj，配置拍照与 TCP，存 img.bmp
- [ ] **五程序按序联调**：背熟启动顺序，跑通 1 件全流程

### C. 必须背下来的"作弊条"（现场禁带电子设备）
- [ ] TCP 连接顺序（下料服务端→视觉→分类→上料）
- [ ] 端到端时序的信号词（run/arrive1/getphoto1/OK/arrive2/getphoto2）
- [ ] Dobot 关键函数签名（连接/夹爪/SetPTPCmdEx/EMotor/红外/GetPose）
- [ ] ResNet 训练参数（224、灰度3通道、SGD0.001、迭代50、每类≥2张）
- [ ] RFID 参数（块1、密钥FFFFFFFFFFFF、前10字节、gbk）
- [ ] 各模块 COM/端口与常见报错处理

### D. 三套主题各跑通一遍（关键）
现场只会用其中一套，但备赛要三套都演练过：
