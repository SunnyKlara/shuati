## 模块 1：下料机械臂 `下料机器臂/Main.py`（总调度中枢）

### 角色
- **TCP 服务端**，绑定 `127.0.0.1:8081`，`listen(5)`。
- 按顺序 `accept()` 三个客户端，每个开一个线程处理。
- 是整个系统的"大脑"，决定流程走向和码垛逻辑。

### 启动后的连接顺序（写死，必须遵守）
```python
tcpCliSock1 = accept()  # 视觉端   → 线程 vision()
tcpCliSock2 = accept()  # 分类端   → 线程 classification()
tcpCliSock3 = accept()  # 上料端   → 线程 load_material()
# tcpCliSock4 = accept() # 语音端  → 默认注释
```

### 4 个线程职责
| 线程 | 收到的信号 | 动作 |
|---|---|---|
| `vision()` | `"M..."`(编号) | 存为 M_number，回 "OK" |
| | `"OK"` | 等3秒，把 M_number 发给分类端 |
| | `"GP1NG"/"GP2NG"` | 让视觉重拍 getphoto1/2 |
| `classification()` | 类别名（如 `1.jqr`）| 抓料→算垛位→放置→add_up++ |
| `load_material()` | `"arrive1"` | 让视觉 getphoto1 |
| | `"arrive2"` | 等5秒→让视觉 getphoto2 |
| `voice()` | `[...]` 语音文本 | 原点/开始/前后左右上下移动 |

### 码垛放置算法（核心）
```python
P3 = [  # 4类 × 2垛，每个 [x,y,z,r]
    [[...垛1...], [...垛2...]],  # 类别0
    ... 共4类
]
add_up = [0,0,0,0]   # 每类已放数量

k = 0 if add_up[index] < 2 else 1   # 前2个放垛1，后2个放垛2
j = add_up[index] % 2               # 偶数底层，奇数上层
delta_z = j * 10                    # 上层抬高10mm
add_up[index] += 1
sum(add_up) == 8 → 结束
```

### 现场必改
1. **第8行 COM 号**：`ConnectDobot(api, "COM6", 115200)` → 改实际端口
2. **第42行 sampleClss**：必须与 ResNet 的 classes 一致
3. **P1/P3/P5/P6 所有坐标**：用读取座标.py 重新示教

### 坑
- 服务端先启动，否则客户端连不上。
- `sampleClss.index(data)` 如果收到的类别名不在列表里会抛异常 → 标签务必对齐。

## 模块 2：上料机械臂 `上料机器臂/Main.py`

### 角色
- **TCP 客户端**，连 `127.0.0.1:8081`。
- 负责：码垛区取料 → RFID位 → 传送带，并控制传送带电机和光电传感器。

### 工作循环
```python
收到 "run" →
  码垛算法算抓取点 P4 (P1 基础上按 x,y 偏移 50mm)
  move(P4) 抓料 → move(P2) 放到RFID位
  发 "arrive1"
  等收到含 "OK" 的回复 →
  move(P2) 抓回 → move(P3) 放传送带
  SetEMotor 启动传送带
  轮询 GetInfraredSensor 等料到位 → 停传送带
  发 "arrive2"
```

### 码垛取料算法
```python
P4[1] = P1[1] - (y * 50)   # Y方向每件偏移50mm
P4[0] = P1[0] - (x * 50)   # X方向
if y < 3: y += 1           # 一列放4件
else: y = 0; x = 1         # 换列
```

### 关键硬件控制
```python
dType.SetEMotor(api, 0, 1, 10000, 1)    # 启动传送带（速度10000）
dType.SetEMotor(api, 0, 0, -10000, 1)   # 停传送带
dType.SetInfraredSensor(api, 1, 1, version=1)  # 使能光电，端口1
i = dType.GetInfraredSensor(api, 1)     # 读光电，i[0]==1 表示有料
```

### move() 函数（夹爪版）
```python
def move(x, y, z, r, air1, air2, keep):
    SetEndEffectorGripper(api, air1, 1)  # 夹爪状态
    SetPTPCmdEx(api, 1, x, y, z+50, r)   # 上方
    SetPTPCmdEx(api, 1, x, y, z, r)      # 下降
    SetEndEffectorGripper(api, air2, 1)  # 抓/放
    SetPTPCmdEx(api, 1, x, y, z+50, r)   # 抬起
    if keep == 0: SetEndEffectorGripper(api, 0, 0)
```

### 现场必改
- **COM 号**（默认 COM16）
- **P1（码垛起点）/P2（RFID位）/P3（传送带）** 三个坐标示教

## 模块 3：深度学习分类 `深度学习分类/main.py` + `ResNet.py`

### main.py 流程
```python
连 8081（客户端）→ remove_result() 清旧图 →
循环:
  recv 数据
  if "M" in data:                       # 收到编号触发识别
    img = cv2.imread("./img.bmp")        # 读视觉拍的图
    result = predict(img)                # ResNet18 推理
    code = get_decoded_text()            # 读 RFID json: "省份;时间"
    省份, 时间 = code.split(";")
    socket.send(result[0])               # 把类别发给下料机
    showResult(...)                      # 弹窗显示5秒
```

```python
classes = ('1.jqr','2.jxb','3.plc','4.sjxt')   # ← 改主题时改这里
tsfrm = Compose([
    Grayscale(3), Resize((224,224)), ToTensor(),

model = resnet18(pretrained=False)
```

### 训练（换主题或识别不准时）
```bash
# 步骤1：raw/ 下4个类别文件夹各放≥2张图
# 步骤2：python createTrainPhoto.py   （每张转20个角度，7:3分train/val）
# 步骤3：python train.py              （迭代50次左右，输出 model/model.pkl）
```

### ⚠️ train.py 已知问题（备赛要知道）
1. `percent = int(num_of_img * 1)` → 实际把 100% 当验证集（注释说20%），train/val 重叠。
2. 验证集也做了随机旋转/翻转 → val acc 会抖动。
3. `scheduler.step()` 在 `optimizer.step()` 前调用 → 新版 PyTorch 警告。

> 这些不影响"能跑出模型"，但如果要追求识别率，可以修正。备赛时知道即可。

### 现场必改
- `ResNet.py` 的 `classes` 和 `train.py` 的 `folder_list` 要一致
- 换主题必须重训模型

## 模块 4：RFID `RFID64bit/RFID.py`

### 作用
读物料背面 M1 卡，输出 `省份;时间`（如 `广东省;1天`）。

### 关键参数
```python
TARGET_BLOCK = 1            # 读块1
SECTOR = 0                  # 块1属于扇区0
DEFAULT_KEY = "FFFFFFFFFFFF"  # 默认密钥A/B
# 取前10字节，按 gbk→gb2312→utf-8→ascii 解码
# 自动扫 COM2–COM20，波特率115200
```

### 数据流
```
RFID.py 读卡 → 解码 → 存 card_result.json
   {"decoded_text": "广东省;1天", ...}
分类 main.py → get_decoded_text() 读 json → split(";")
```

### 现场操作
1. 单独运行 `python RFID.py`，把卡放读卡区。
2. 看到 `解码文本: 广东省;1天` 即成功。
3. **保持 RFID.py 运行**，不要中断（中断会占用端口）。

### 坑
- 连接失败/找不到 → 端口占用 → 拔插 USB。
- 读乱码 → 卡密钥被改过，或不是块1。

## 模块 5：视觉 `视觉工程文件/40307.poj`

### 作用
DobotVisionStudio（多功能机器视觉软件 3.1.6）工程，负责：
- 拍照取图
- 读物料编号（识别 "M00X" 或二维码）
- 把物料本体图存为 `深度学习分类/img.bmp`
- 通过 TCP 连 8081，收 `getphoto1`/`getphoto2` 触发拍照

### 现场操作（在软件里，不是代码）
1. 打开软件 → 加载 `40307.poj`
2. 确认相机出图清晰（调焦/调光/USB3.0）
3. 确认 TCP 通信模块：客户端连 127.0.0.1:8081
4. 确认拍照流程：getphoto1 拍编号、getphoto2 拍本体存 img.bmp
5. **每改一步另存新文件名**（40307_v1.poj…）防崩溃丢进度

### 坑
- 无图/卡顿 → USB 插 3.0 蓝口
- 软件崩溃 → 参数错，另存新文件
- 图模糊 → 待物料到位后延时再拍（代码已有 sleep5）

## 模块 6：语音 `语音/aip-python-sdk-4.16.14/main.py`（可选加分）

### 作用
百度云 ASR 语音控制机械臂。下料机里默认**注释掉**，是加分项。

### 流程
```python
连 8081 → 收 "run" → 录音5秒 → 上传百度ASR → 返回文本
下料机 voice() 解析：
  "原点" → 回零点 P5
  "开始" → 启动分拣（发 run 给上料和分类）
  "前/后/左/右/上/下 + 数字厘米" → 相对移动
```

### 启用方法
1. 取消下料机 Main.py 里 `tcpCliSock4` / `voice` 线程的注释。
2. 启动顺序末尾加 `python 语音/main.py`。
3. 需要联网（百度云 API）。

### 坑
- 需联网，赛场网络不确定 → 作为加分项，主流程不依赖。
- pyaudio 安装可能失败 → 提前装好。
