## 四、逐模块验证（无硬件也能做的部分）

### 验证 1：深度学习分类——推理能跑
```python
# 在 深度学习分类/ 目录运行
import cv2
from ResNet import predict
img = cv2.imread("img.bmp")   # 先放一张测试图
result = predict(img)
print(result)   # 期望输出：('1.jqr', 0, 0.95) 这样的元组
```
- `result[0]`：类别名
- `result[1]`：类别编号（0–3）
- `result[2]`：置信度（>0.7 才算有效）

### 验证 2：RFID 读卡——DLL 加载正常
```python
# 在 RFID64bit/ 目录运行
from RFID import M1CardReader
r = M1CardReader()
print("DLL 加载成功")   # 不报错即可（无读卡器也能过这步）
```

### 验证 3：深度学习——训练流程能跑
```bash
# 在 深度学习分类/ 目录
# 1. 先往 raw/1.jqr/ 里放至少2张图（从 物料/ 下的图截取）
# 2. 生成数据集
python createTrainPhoto.py
# 期望：输出 "complete!" 且 data/train/ data/val/ 有文件

# 3. 训练（哪怕只跑 5 轮看有没有报错）
# 改 train.py 的 num_epochs=5 先试跑
python train.py
# 期望：输出每轮 Loss 和 Acc，最后保存 model/model.pkl
```

### 验证 4：TCP 通信——下料机服务端能启动
```python
# 在 下料机器臂/ 目录（改 COM 号为不存在的先忽略连臂报错）
# 注释掉 dType.ConnectDobot 那行，只测 TCP 部分
import socket
srv = socket.socket()
srv.bind(('127.0.0.1', 8081))
srv.listen(5)
print("8081 监听中")   # 不报错即可
srv.close()
```

## 五、常见安装/运行报错速查

| 报错 | 原因 | 解决 |
|---|---|---|
| `DLL load failed` | DobotDll.dll 或 comPro64.dll 不在同目录 | 把 dll 复制到 .py 同级目录 |
| `No module named torch` | torch 未装 | `pip install torch torchvision` |
| `cv2 imshow 崩溃` | headless 环境无显示 | 换 `opencv-python`（非 headless）|
| `OSError: COM port not found` | 串口不存在（无硬件） | 正常，先跑软件部分 |
| `Address already in use` | 8081 被占用 | 任务管理器结束上次 python 进程 |
| 视觉软件崩溃 | 参数输入错误 | 另存为新文件名，不覆盖旧工程 |
| 运行库报错 | VC++ 运行库缺失 | 解压 `运行库报错.rar` 安装 |
