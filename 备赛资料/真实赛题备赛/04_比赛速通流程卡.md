## 全场高风险快速处置表

| 现象 | 立刻做 |
|---|---|
| 终端1卡在`accept()`不动 | 检查后续程序是否按序启动了 |
| 连臂失败/端口不存在 | 设备管理器确认COM号，重改代码 |
| 端口占用（RFID/臂）| 任务管理器结束所有python进程，拔插USB，重启 |
| 视觉软件崩溃 | 另存新文件名后重开，不要覆盖旧工程 |
| 相机无图/卡顿 | 确认USB插3.0蓝口 |
| 识别置信度<0.5 | 检查光照→重拍→必要时重训 |
| 放置偏差大 | 读取座标.py重示教对应P点 |
| 夹爪不动报警 | 重启，代码开头ClearAllAlarmsState已写好 |
| 传送带不停/乱停 | 检查光电传感器水平/检测距离，调螺丝 |
| 收不到arrive2 | 光电传感器没感应到料，检查高度和水平 |
