## 核心认知：所有机械臂程序都是这 4 块拼的

```
第①块：导入 + 连接机械臂   （几乎一字不变，背死）
第②块：初始化设置          （几乎一字不变，背死）
第③块：定义 move() 抓放函数 （骨架固定，背死）
第④块：主逻辑              （按任务变，理解为主）
```

记住：**①②③ 是模板，几乎不变；只有 ④ 需要动脑。** 先把①②③练到闭眼能敲。

## 第①块：导入 + 连接（背死，每个程序开头都一样）

```python
import DobotDllType as dType
import socket
import time

# 加载库
api = dType.load()

# 连接机械臂（COM号现场改！）
state = dType.ConnectDobot(api, "COM6", 115200)[0]
print("连接状态:", ["已连接", "未找到设备", "端口占用"][state])
```

**记忆点：**
- `dType.load()` → 先加载
- `ConnectDobot(api, "COM6", 115200)[0]` → 连接，**结尾 `[0]` 别忘**（取状态码）
- 三个参数顺序：api、COM号字符串、波特率115200

## 第②块：初始化设置（背死，连接成功后必做）

```python
dType.ClearAllAlarmsState(api)              # 清警报（不清可能不动）
dType.SetPTPJumpParams(api, 100, 110, isQueued=1)   # 门型抬升参数
dType.SetEndEffectorParams(api, 59.7, 0, 0, 1)      # 夹爪长59.7mm
dType.SetQueuedCmdClear(api)                # 清空指令队列
dType.SetQueuedCmdStartExec(api)            # 开始执行队列
dType.SetEndEffectorGripper(api, 0, 0, isQueued=1)  # 夹爪初始打开
dType.SetHOMECmd(api, 1, isQueued=1)        # 回零
```

**记忆口诀：清警报 → 设跳跃 → 设夹爪 → 清队列 → 开队列 → 张爪 → 回零**
（"清设设清开张回" 七个动作）

## 第③块：move() 抓放函数（背死，这是机械臂的"手"）

```python
def move(x, y, z, r, air1, air2, keep):
    dType.SetEndEffectorGripper(api, air1, 1, isQueued=1)   # 到达前夹爪状态
    dType.SetPTPCmdEx(api, 1, x, y, z + 50, r, isQueued=1)  # 先到上方50mm
    dType.SetPTPCmdEx(api, 1, x, y, z, r, isQueued=1)       # 下降到点
    dType.SetEndEffectorGripper(api, air2, 1, isQueued=1)   # 抓或放
    dType.dSleep(100)                                        # 等0.1秒
    dType.SetPTPCmdEx(api, 1, x, y, z + 50, r, isQueued=1)  # 抬回上方
    if keep == 0:
        dType.SetEndEffectorGripper(api, 0, 0, isQueued=1)  # 不保持就张爪
```

**记忆逻辑（理解了就不用死背）：**
抓放永远是 **上 → 下 → 动爪 → 上** 这个"门字形"。
- `z + 50` 是安全高度（先到上方，避免撞）
- 中间 `SetEndEffectorGripper` 决定这次是抓（合）还是放（开）
- `SetPTPCmdEx(api, 1, ...)` 的 **1 是运动模式**（MOVJ），固定写1

**参数含义：**
- `air1`：到达目标前夹爪开/合
- `air2`：到达后夹爪开/合（抓=合1，放=开0）
- `keep`：1=保持夹着不松，0=松开

## 第④块：主逻辑（理解为主，按角色不同）

### 如果是"客户端"角色（上料机/分类机）
```python
# 连服务端
socket_client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
socket_client.connect(("127.0.0.1", 8081))
print('连接成功')

# 循环收指令做事
while True:
    data = socket_client.recv(1024).decode('utf-8')
    print(data)
    if data == 'run':              # 收到run就干活
        move(...)                  # 抓放动作
        socket_client.send("arrive1".encode('utf-8'))  # 干完回报
```

### 如果是"服务端"角色（下料机）
```python
socket_server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
socket_server.bind(('127.0.0.1', 8081))
socket_server.listen(5)
conn, addr = socket_server.accept()    # 等客户端连
# 之后 conn.recv / conn.send 收发
```

**记忆点（客户端3步）：socket() → connect() → recv/send 循环**
**记忆点（服务端4步）：socket() → bind() → listen() → accept()**

---

## TCP 收发的固定写法（背死）

```python
# 收（解码）
data = socket_client.recv(1024).decode('utf-8')

# 发（编码）
socket_client.send("内容".encode('utf-8'))
```

**口诀：收要 decode，发要 encode，都带 'utf-8'，recv 里写 1024。**
