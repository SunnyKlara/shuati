## 二、无真机也能练的（现在立刻开始，占备赛 50%）

### 训练 A：把 6 个模块代码读懂能复述（1 天）
- 对照 `02_六大模块逐个精讲.md`，逐个程序讲出"它干什么、收什么信号、发什么信号"。
- 自测：能不能默画出"一件物料的端到端时序图"？

### 训练 B：深度学习模型训练全流程（重点，2 天）
这是**无硬件就能完整练**的核心技能，也是换主题的关键。
```bash
# 1. 从 物料/快递物料/ 里取图，放进 raw/ 的4个类别文件夹
# 2. python createTrainPhoto.py     → 看 data/ 生成
# 3. python train.py（先 epochs=5 试跑）→ 看 model.pkl 生成
# 4. python -c "import cv2; from ResNet import predict; print(predict(cv2.imread('img.bmp')))"
```
**练到三套主题都能独立重训：**
- [ ] 工业自动化（默认 jqr/jxb/plc/sjxt）
- [ ] 快递物料（电子产品/食品/服装/书籍）
- [ ] 自动驾驶（交通锥/智能路障/仿真测试/测试车辆）

> 换主题清单：① 改 `ResNet.py` classes ② 改 `train.py` folder_list ③ 改 `下料机Main.py` sampleClss ④ raw/ 换图重训。

### 训练 C：TCP 时序模拟（1 天，无硬件）
用 TCP 调试助手或 Python 模拟，理解信号往来：
- 自己写个小服务端绑 8081，手动发 run/arrive1/getphoto1 等信号，观察程序反应。
- 把下料机 Main.py 的 ConnectDobot 注释掉，只跑 TCP 部分看线程逻辑。

### 训练 D：背"作弊条"（贯穿始终）
- [ ] TCP 启动顺序：下料服务端→视觉→分类→上料
- [ ] 信号词：run/arrive1/getphoto1/M00X/OK/arrive2/getphoto2/类别名
- [ ] Dobot 函数：ConnectDobot/SetEndEffectorGripper/SetPTPCmdEx/SetEMotor/GetInfraredSensor/GetPose/ClearAllAlarmsState
- [ ] ResNet 参数：224、灰度3通道、SGD0.001、StepLR、迭代50、每类≥2张
- [ ] RFID：块1、密钥FFFFFFFFFFFF、前10字节、gbk、省份;时间

## 三、有真机才能练的（培训日/学校设备/赛前，占 50%）

### 训练 E：组装计时（练到 ≤8 分钟）
- 双臂 + 相机模组 + 传送带 + 光电传感器 + RFID 读卡器。
- 重点：光电传感器接 GP2 口、水平放置；相机 USB 插 3.0。
- 反复完整拆装，计时记录。

### 训练 F：坐标示教（最耗时、最关键）
用 `读取座标.py`（改 COM 号），手动拖臂到每个点记录：
- 上料臂：P1（码垛起点）、P2（RFID位）、P3（传送带）
- 下料臂：P6（传送带抓取）、P3[4类][2垛]（8个放置点）
- 练到：闭眼也知道先示教哪个点、坐标怎么填回 Main.py。

### 训练 G：单件全流程联调
按顺序启动五程序 → 跑通 1 件 → 再扩展到 8 件。
- 记录每件的识别结果、放置是否准确。
- 标定/示教不准就回训练 F 微调。

### 训练 H：异常恢复演练
- 端口占用 → 杀进程/拔插 USB
- 程序卡 accept → 检查启动顺序
- 识别错 → 看置信度，必要时重训
- 夹爪不动 → 重启清警报

## 五、培训第3天"自由实操"必做清单（决定名次）

带目标去，别瞎试：
1. 完整组装 1 遍并计时。
2. 用读取座标.py 把所有 P 点示教记录下来（**拍不了照就手抄坐标**）。

   - [ ] 模型能不能赛前训好拷进去？还是现场重训？

5. 把卡住的地方记下来，回来逐个解决。

## 六、和 Kiro 一起训练的方式
- **出题考你**：从 `05_真题自测题库.md` 抽题或针对薄弱项出新题。
- **代码默写检查**：你写一段（连接/夹爪/EMotor/训练），我挑错。
- **换主题演练**：我给你一套新主题，你改 4 处配置 + 重训，我验收。
- **联调模拟**：我扮演某个模块，给你发信号，你说下一步该干嘛。
- **复盘**：真机练习后把问题发我，我帮定位、更新避坑清单。

> 想开始就说「出 5 道真题考我」或「带我练换主题重训」。
