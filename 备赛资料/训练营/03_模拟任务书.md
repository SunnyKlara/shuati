# 任务 A：单色形状分拣（入门）

## 背景
检测平台上放置若干工件，形状为 **圆形、正方形、三角形** 三种，颜色统一（如黑色）。
要求识别每个工件形状，并用机械臂分拣到对应放置区。

## 任务要求
1. 完成相机+机械臂硬件组装与连接。
2. 完成手眼标定，标定误差 ≤ 2mm。
3. 编写视觉程序：识别工件形状 + 输出像素/物理坐标。
4. 通过 TCP 将识别结果发送给机械臂控制程序。
5. 机械臂将 **8 个随机摆放**的工件分拣到：
   - 圆形 → A 区
   - 正方形 → B 区
   - 三角形 → C 区

## 放置区坐标（示例，现场以任务书为准）
| 区 | 形状 | X | Y |
|---|---|---|---|
| A | circle | 250 | 80 |
| B | square | 250 | 0 |
| C | triangle | 250 | -80 |

## 评分表（100 分）
| 项目 | 分值 | 评分点 |
|---|---|---|
| 硬件组装 | 15 | 完整性、牢固性、相机视野正确 |
| 手眼标定 | 15 | 误差≤2mm 满分，>5mm 不得分 |
| 程序设计 | 20 | 识别逻辑合理、代码结构清晰、通信打通 |
| 识别正确率 | 25 | 8件，每件正确识别 ~3分 |
| 分拣正确率 | 25 | 8件，每件放对区 ~3分 |
| 用时 | （计入排名） | 完成越快排名越靠前 |

## 用 practice 工程怎么练
- 这就是 `demo_offline.py` / `tcp_server.py + tcp_client_vision_sim.py` 的默认场景。
- 跑通后，把放置区坐标改成上表，重新跑，确认每件放对区。

# 任务 B：颜色 + 形状 双条件分拣（进阶）

## 背景
工件有 **3 种形状 × 2 种颜色（红/蓝）**，需同时识别形状和颜色，按组合分拣。

## 任务要求
1~4 同任务 A，但识别要**同时输出 形状 + 颜色**，label 形如 `red_circle`。
5. 分拣规则：
   - 红色 → 左侧三个区（按形状细分）
   - 蓝色 → 右侧三个区（按形状细分）

## 放置区（示例）
| label | X | Y |  | label | X | Y |
|---|---|---|---|---|---|---|
| red_circle | 230 | 90 | | blue_circle | 230 | -90 |
| red_square | 250 | 90 | | blue_square | 250 | -90 |
| red_triangle | 270 | 90 | | blue_triangle | 270 | -90 |

## 评分表（100 分）
| 项目 | 分值 |
|---|---|
| 硬件组装 | 10 |
| 手眼标定 | 15 |
| 程序设计（双条件识别） | 25 |
| 识别正确率（形状+颜色都对才算对） | 25 |
| 分拣正确率 | 25 |

## 用 practice 工程怎么练（动手改代码）
1. 改 `vision_opencv.py`：在 `detect_shapes` 里加 **HSV 颜色判断**，
   对每个轮廓取其内部平均色相，判红/蓝，label 拼成 `red_circle`。
2. 改 `vision_opencv.py` 的 `make_synthetic_scene`：让工件随机红/蓝两色。
3. 改 `sorter.py` 的 `PLACE` 字典：加入 6 个组合的坐标。
4. 跑 `demo_offline.py` 验证。

> 提示：取轮廓内部颜色可用掩膜 `mask = np.zeros(...); cv2.drawContours(mask,[c],-1,255,-1)`，
> 再 `cv2.mean(hsv, mask=mask)` 取平均 HSV。

# 任务 C：综合分拣 + 二维码/字符（决赛级）

## 背景
工件表面贴有**二维码或字符编号**，需识别编号决定去向；部分工件需按**形状+编号**双重判定。
模拟"产线按订单号分拣"场景。

## 任务要求
1. 硬件组装 + 标定（误差≤1.5mm，决赛级更严）。
2. 视觉程序需具备：
   - 形状识别
   - **二维码识别**（输出编码字符串）或 **字符识别 OCR**（输出编号）
3. 分拣规则（示例）：
   - 编号以 `A` 开头 → 1 号区
   - 编号以 `B` 开头 → 2 号区
   - 无法识别编号的 → 回收区
4. 8 件随机摆放，含 1~2 件"故意难认"（角度倾斜/部分遮挡），考验鲁棒性。

## 评分表（100 分）
| 项目 | 分值 |
|---|---|
| 硬件组装 | 10 |
| 手眼标定（≤1.5mm） | 15 |
| 程序设计（含二维码/OCR） | 25 |
| 识别正确率 | 25 |
| 分拣正确率 | 20 |
| 异常处理（难认件不乱抓、能进回收区） | 5 |

## 用 practice 工程怎么练
1. 安装 `pip install pyzbar`（二维码解码）或用 `cv2.QRCodeDetector()`。
2. 在 `vision_opencv.py` 里给合成工件**贴上二维码图案**（可用 `qrcode` 库生成小图贴上去）。
3. 识别流程：先定位工件 → 截取工件区域 → 解码二维码 → 按编号决定 label。
4. 在 `sorter.py` 加"回收区"坐标 + 未识别时的兜底逻辑。
5. 跑通后故意把某个二维码模糊化，验证它进回收区而不是乱放。

## 三套任务的训练节奏建议
- **第 1 周**：吃透任务 A（最重要，决赛大概率就是 A 或 A+颜色）。
- **第 2 周**：任务 B，练双条件识别。
- **行有余力**：任务 C，练二维码/OCR 和鲁棒性（加分项，冲国一用）。
