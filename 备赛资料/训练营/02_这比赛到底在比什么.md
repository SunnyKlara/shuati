# 02 这比赛到底在比什么（大白话版）

> 你现在一点思路都没有，很正常。先把整件事讲成一个"故事"，看完你就懂了。

---

## 一句话概括

> **给你一台会动的机械臂 + 一个朝下拍的摄像头。桌上随机撒 8 个不同形状的小工件，
> 你要写程序让摄像头"看出"每个是什么形状、在哪，然后指挥机械臂把它们一个个抓起来，
> 分门别类放到对应的盒子/区域里。谁装得快、认得准、分得对，谁名次高。**

就这么简单。它不是写算法题、不是做 App，是**"看得见 + 抓得到"的动手活**。

---

## 比赛当天，你会经历什么（按时间顺序走一遍）

### 第 0 步：抽工位、拿任务
- 抽签决定坐哪个工位。
- 裁判发给你：**任务书**（今天具体要干啥）、**评分标准**、**每种形状各 1 个样品**（让你先看清楚要认哪些形状）。

### 第 1 步：装设备（≤10 分钟，计时评分）
- 桌上是一堆零件：机械臂、摄像头、支架、光源、螺丝。
- 你用**自带的内六角扳手**，把摄像头装到支架上（朝下、距桌面约 50cm），把机械臂摆好，插上电和 USB。
- 裁判检查你装得**对不对、牢不牢、全不全** → 给分。
- ⚠️ 这步纯熟练度，**练 10 遍就能 6 分钟装完**。

### 第 2 步：编程 + 调试（≤80 分钟，评分）
这是主战场，4 件事：
1. **取图**：打开摄像头，调焦、调光源亮度，让画面清晰。
2. **识别**：用 DobotVisionStudio（拖拽式视觉软件）或 Python，
   认出每个工件是 圆/方/三角（可能还要认颜色/二维码/字符），并算出它在画面里的**像素坐标**。
3. **手眼标定**：摄像头看到的是"画面里的像素位置"，机械臂听得懂的是"现实里的毫米坐标"。
   标定就是建立这两者的换算关系。**这步最容易翻车，是拉开差距的关键。**
4. **联调（TCP 通信）**：把"识别出的类别+坐标"通过网络（TCP）发给机械臂控制程序，
   机械臂收到后去抓、去放。

### 第 3 步：现场实跑（≤10 分钟，看正确率）
- 裁判把 **8 个工件随机摆**在台上。
- 你按"开始"，机械臂自动一个个识别+抓取+分类放好。
- 抓对几个、放对几个 → 直接算分。

## 用到的三样东西，分别是干嘛的

| 工具 | 角色 | 类比 |
|---|---|---|
| **工业摄像头 + 光源** | 机械臂的"眼睛" | 你的眼睛 |
| **DobotVisionStudio** | 视觉软件，负责"看懂"（识别+定位+标定） | 你的"大脑认物"部分 |
| **Dobot Magician 机械臂** | 执行"抓取分拣"动作 | 你的手臂 |
| **Python + TCP** | 把"眼睛/大脑"和"手"连起来、写控制逻辑 | 神经，传命令 |

数据是这样流动的：
```
摄像头拍照 → 视觉软件认出"这是圆形，在画面(320,240)处"
          → 标定换算成"机械臂坐标(225, 0)毫米"
          → 通过 TCP 发给 Python 控制程序
          → 机械臂走过去，吸盘吸住，搬到"圆形区"放下
```

> 这正是你 `practice/demo_offline.py` 跑的那套流程——它把上面整条链路用代码模拟了一遍。
> **建议现在就跑一次 `python demo_offline.py`，你会看到机械臂一步步"PTP移动→吸盘ON→搬运→吸盘OFF"，
> 比看文字直观一百倍。**

## 为什么"每种形状各发 1 件"很关键
任务书发样品，是让你**赛前先把每种形状的识别参数调好**（比如圆的圆度阈值、方的边数）。
所以现场策略是：**先用样品把识别和标定调准（单件能抓对），再让裁判撒 8 件跑全场。**
