## 评分要点（答完再看）

<details><summary>第一部分</summary>

1. 不能用。相机一动，像素↔物理映射关系全变。**必须重新标定**。省时做法：标定点位置/流程已熟，快速重标 4~9 点并验证。（这也是为什么相机支架要锁死、别碰）
2. **警惕**。4 个点解 6 参数仿射接近"恰定/过拟合"，残差小不代表真准；应**多取点(如9点)**或留**独立验证点**实测误差。
3. 真空度不足/气泵没使能、吸盘没贴合工件表面(高度Z没到位)、工件表面不平/透气、吸盘老化漏气、enableControl 没置1、抓取延时太短还没吸住就抬。
4. JUMP 更安全。它先抬到安全高度再平移最后下降，**不会在工件高度横扫**撞倒其他件；MOVL 直线插补可能贴着桌面平移撞件。
5. 按协议**字段数!=4 视为非法，回 ERR 并跳过**，继续处理后续。不能崩——一条坏数据不能让整场分拣停摆（鲁棒性）。
6. 旋转 45° 的方形**边数仍是4**，approxPolyDP 判别不受影响（仿射不变）；圆度判别本就靠面积/周长比，也不受旋转影响。真正的坑是**角度**要靠 minAreaRect 取。
7. ①调亮/调匀光源、加 ROI；②改用自适应阈值 `adaptiveThreshold` 或先做对比度增强(CLAHE)/形态学；也可换固定阈值人工调。
8. 目标坐标**超出机械臂可达工作空间**（或奇异/限位），Magician 会锁死。需把坐标限制在可达范围内。
9. ①用 **JUMP** 抬高搬运避免横扫；②**按距离/区域排序**先抓离放置区近或外围的；③放置区拉开间距；④必要时分拣前**重新拍照更新坐标**。
10. 合理答案：**先识别后标定**或**先标定后识别**都可，关键是给出理由。推荐：先取图把识别跑通(确认认得对)，再标定(把坐标对齐)，因为识别不通标定也没意义；但两者都要尽快，最终以"单件能抓对"为里程碑。
</details>

<details><summary>第二部分</summary>

**T1 要点**：遍历转换坐标，计算 `r=hypot(X,Y)`，`150<=r<=330` 保留，否则丢弃计数。就地改 `d.x,d.y`。
```python
import math
def pixel_to_robot_batch(dets, he):
    valid, dropped = [], 0
    for d in dets:
        X, Y = he.pixel_to_robot(d.x, d.y)
        if 150 <= math.hypot(X, Y) <= 330:
            d.x, d.y = round(X,2), round(Y,2); valid.append(d)
        else:
            dropped += 1
    return valid, dropped
```
**T2 要点**：取掩膜内平均 HSV；红色 H 在 0 和 180 附近**两段**都要判。

**T3 要点**：循环 retries，每次新建 socket+settimeout，成功即 return，except 续试，最后 raise。
```python
import socket
def send_with_retry(host, port, line, retries=3, timeout=2.0):
    last = None
    for _ in range(retries):
        try:
            s = socket.socket(); s.settimeout(timeout)
            s.connect((host, port)); s.sendall(line.encode()); s.close(); return True
        except OSError as e:
            last = e
    raise ConnectionError(f"发送失败: {last}")
```
